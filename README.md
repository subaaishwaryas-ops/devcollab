# DevCollab

A real-time project collaboration platform for developer teams.

## Features
- Workspace & Project Management with role system
- Kanban Board (To Do → In Progress → In Review → Done)
- Task priorities (P0/P1/P2), descriptions
- AI Project Assistant powered by Google Gemini
  - Summarise project progress
  - Identify blockers
  - Generate daily standup reports
- Code Snippet Manager with syntax highlighting and copy button
- Sandbox Payments (Razorpay Test Mode)

## Tech Stack
- Frontend: Next.js 14, Tailwind CSS, TypeScript
- Backend: Next.js API Routes
- Database & Auth: Supabase (PostgreSQL)
- AI: Google Gemini 2.0 Flash
- Deployment: Vercel
